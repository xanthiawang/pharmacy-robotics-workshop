药房机器人工作坊

重新摆放药房家具，在仿真中观察机械臂和灵巧手抓起药盒、放进周转箱。

下载完整资产包 查看操作说明

下载和查看完整说明需要 GitHub 仓库访问权限。

布局与仿真

  1. 1. 调整家具

    在 URDF Studio 打开包内 .botscene，摆放柜子、椅子和中央桌，再保存布局。

  2. 2. 转换布局

    打开资产包里的「布局转BotLab.html」，选择保存的布局，下载 BotLab 工程。

  3. 3. 运行抓取

    在 BotLab 中导入 .botlab.zip，点击 Run。

单独设计模型

在 Blender 打开完整药房或空房间的 .blend。可以调整柜子的结构，也可以从零设计新模型。
